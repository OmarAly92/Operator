---
title: Cursor
description: Built-in Terminal UI support for the Cursor Agent CLI.
---

Operator's Cursor adapter resolves the Cursor Agent CLI from your machine and checks its local readiness through the agent catalog.

```bash
opr agent ls --refresh
opr spawn --project my-app --name cursor-task --agent cursor
```

Operator runs Cursor's native terminal UI in the session worktree.

Operator records activity through the adapter's supported hooks and terminal signals. There is no Cursor npm plugin or `operator.yaml` block to install.
