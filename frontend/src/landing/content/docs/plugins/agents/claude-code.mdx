---
title: Claude Code
description: Built-in terminal support for the user's Claude Code installation.
---

Operator resolves the `claude` executable from your machine and reuses its existing authentication. Install and sign in with Claude Code before refreshing the Operator catalog.

```bash
opr agent ls --refresh
opr spawn --project my-app --name claude-task --agent claude-code
```

Operator runs the native Claude Code CLI in the session worktree.

Operator installs its supported activity hook during workspace setup. Use `opr agent ls --refresh --json` for install/auth diagnostics rather than editing a plugin block.
