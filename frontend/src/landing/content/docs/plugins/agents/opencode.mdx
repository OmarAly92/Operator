---
title: OpenCode
description: Built-in terminal support for the user's OpenCode installation.
---

Operator resolves your local `opencode` executable and reuses its authentication.

```bash
opr agent ls --refresh
opr spawn --project my-app --name opencode-task --agent opencode
```

Operator runs OpenCode's native terminal UI in the session worktree.

OpenCode is also a shipped reviewer harness. Reviewer configuration is independent from the worker harness; inspect project settings and `opr review --help` for the current review workflow.
