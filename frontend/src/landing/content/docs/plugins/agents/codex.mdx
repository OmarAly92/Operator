title: Codex
description: Built-in Terminal UI and native app-server Chat support for the user's Codex installation.
---

Operator uses the locally installed `codex` executable and its existing OpenAI authentication.

```bash
opr agent ls --refresh
opr spawn --project my-app --name codex-task --agent codex --mode chat
```

## Interfaces

- **Terminal UI:** runs the native Codex CLI in the session worktree.
- **Chat:** connects to Codex's native app-server protocol and persists the provider conversation identity with the Operator session.

Codex supports the same capability-gated Chat/Terminal UI handoff as Claude Code. The Operator session and worktree remain stable across a compatible handoff.

Operator performs bounded installation and authentication probes before spawn. Use `--skip-agent-check` only to bypass that advisory CLI preflight; daemon validation remains authoritative.
