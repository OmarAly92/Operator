---
title: Terminal surface
description: The built-in desktop terminal backed by Operator's WebSocket mux.
---

Operator does not select between terminal plugins. The desktop app provides an xterm-based terminal surface and the daemon exposes a WebSocket terminal mux.

The mux attaches each session to its platform runtime: `tmux` on macOS/Linux and ConPTY on Windows. A separate shell can be opened in the same session worktree.

See [desktop terminal](/docs/plugins/terminals/web) for connection behavior.
