Operator (**Operator**) is a desktop IDE for supervising AI coding agents. It gives workers isolated workspaces, keeps each conversation or terminal available, and connects Git-project work to pull requests, CI, reviews, and merge conflicts.

The agents still write the code. Operator provides the control layer around them: projects, sessions, workspaces, status, follow-up messages, review runs, notifications, and external browser previews in one place.

<Callout type="info" title="Fastest path">
	Download the desktop app, add a repository, and start one small session. See [Installation](/docs/installation), then [Quickstart](/docs/quickstart).
</Callout>

## What Operator Helps You Do

- Run several coding agents without mixing their files, branches, or pull requests.
- Run each session in its agent's native terminal UI.
- Follow activity, CI, review feedback, and merge readiness from the desktop app.
- Send follow-up instructions to the right worker.
- Run reviewer agents and route requested changes back to the worker.
- Preview a session's local app in your default browser.
- Check and respond from the companion mobile app on your home network.

Operator works best when each worker has a clear, reviewable outcome: a focused bug, feature, refactor, test, documentation update, or review follow-up.

## The Basic Loop

```text
add project -> start session -> isolated worktree -> pull request -> CI/review -> merge -> cleanup
```

You can create sessions from the desktop app or the optional CLI. Operator launches the selected agent's terminal UI, observes durable activity and pull-request facts, and derives the status shown in the UI.

## Terminal UI

Every session runs the harness's native interactive terminal. Desktop renders it directly. Mobile opens covered harnesses in a hook-derived blocks view by default and can toggle to the raw terminal per session.

## Local By Design

The desktop app runs a Go daemon on `127.0.0.1` and communicates with it over a local API. Durable product state, desktop webview data, and worktree metadata live under `~/.operator` by default. Your agent CLIs and source-control credentials remain your own; Operator does not bundle provider CLIs.

Connect Mobile is a separate, opt-in home-network listener protected by a connection password. It is off until you enable it in the desktop app.

## Supported Agents

Operator includes terminal adapters for more than twenty agent harnesses, including Claude Code, Codex, Cursor, Aider, OpenCode, Droid, Kimi Code, GitHub Copilot, and others.

GitHub is the currently shipped source-control observation path. Broader tracker and SCM integrations described in older Operator documentation are not all available in the current daemon rewrite.
